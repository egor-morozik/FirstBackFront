A small learning project with minimal logic for backend(FastAPI) and frontend(React) interaction, 
as well as nginx connectivity for proxying and distributing frontend statics.

Learning Project Steps:

- Manually linked HTML and API.

- I transferred this logic to React (understood its basic principle).

- I assembled the frontend into static and sent it via Nginx.

- Set up proxying in Nginx so that the frontend and backend communicate via the same port.
